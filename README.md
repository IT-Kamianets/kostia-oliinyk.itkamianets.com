# 🌐 Персональний сайт-резюме та портфоліо | Kostiantyn Oliinyk

Сучасний, адаптивний двомовний вебсайт-резюме та портфоліо студента комп'ютерних наук **Костянтина Олійника** (КПНУ ім. Івана Огієнка).

Створений на базі інженерних відповідей, цінностей, навчального стеку та найкращих курсових проєктів.

---

## 🚀 Основні можливості сайту

- 🇺🇦 / 🇬🇧 **Миттєве перемикання мов (Bilingual i18n)**:
  - Підтримка **української** та **англійської** мов для кожного розділу сайту.
  - Автоматичне збереження вибраної мови користувача в `localStorage`.
- 🌙 / ☀️ **Темна та світла теми (Dark & Light Mode)**:
  - Сучасна кіберпанк/девелоперська темна тема за замовчуванням та чиста контрастна світла тема.
  - Автоматичне збереження вибору теми та визначення уподобань операційної системи.
- 💣 **Інтерактивна демо-гра «Сапер» (Minesweeper)**:
  - Повноцінний інтерактивний симулятор найкращої курсової роботи прямо у вікні браузера.
  - Безпечний перший клік (Safe First-Click generation).
  - Рекурсивний алгоритм відкриття суміжних пустих клітинок (**Flood Fill**).
  - Таймер, лічильник мін, розміщення прапорців 🚩 правою кнопкою миші та реактивні смайлики.
- 🖨️ **Друк та експорт у PDF (Print-ready CV)**:
  - Натискання кнопки **«Завантажити CV (PDF)»** або комбінації `Ctrl + P` відкриває оптимізовану версію для друку / збереження в один або два аркуші формату A4 (приховуються навігаційні кнопки, анімації та модальні вікна, формуючи охайний академічний документ).
- 📱 **Повна адаптивність**:
  - Бездоганне відображення на мобільних телефонах, планшетах, ноутбуках і 4K-моніторах.
- ⚡ **Zero-Dependencies**:
  - Працює автономно без необхідності встановлювати Node.js або зовнішні пакети. Достатньо просто відкрити `index.html` у будь-якому браузері!

## 🏃‍♂️ Як запустити сайт локально

1. Двічі клацніть файл **`index.html`** у вашому провіднику (Windows Explorer), щоб відкрити його в Microsoft Edge, Google Chrome або іншому улюбленому браузері.
2. Також можна відкрити проєкт у **VS Code** і за бажанням запустити розширення **Live Server**.

## 🌐 Як опублікувати сайт в інтернеті (GitHub Pages)

Щоб отримати власне публічне посилання (наприклад, `https://username.github.io/resume`):
1. Створіть новий репозиторій на [GitHub](https://github.com).
2. Завантажте файли `index.html`, `css/` та `js/`.
3. Перейдіть у розділ **Settings** репозиторію -> **Pages**.
4. У пункті **Branch** виберіть `main` (або `master`) та папку `/(root)`, натисніть **Save**.
5. За 1-2 хвилини ваш сайт-резюме буде доступний усьому світу!
