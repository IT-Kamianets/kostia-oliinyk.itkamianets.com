# 🌐 Персональний сайт-резюме та портфоліо | Kostiantyn Oliinyk

Сучасний, адаптивний двомовний вебсайт-резюме та портфоліо студента комп'ютерних наук **Костянтина Олійника** (КПНУ ім. Івана Огієнка).

Створений на базі інженерних відповідей, цінностей, навчального стеку та найкращих курсових проєктів.

---

## 🚀 Основні можливості сайту

- 🇺🇦 / 🇬🇧 **Миттєве перемикання мов (Bilingual i18n)**:
  - Підтримка **української** та **англійської** мов для кожного розділу сайту.
  - Автоматичне збереження вибраної мови користувача в `localStorage`.
- 🌙 / ☀️ **Темна та світла теми (Dark & Light Mode)**:
  - Сучасна кіберпанк/девелоперська темна тема за замовчуванням та чиста контрастна світла тема.
  - Автоматичне збереження вибору теми та визначення уподобань операційної системи.
- 🖨️ **Друк та експорт у PDF (Print-ready CV)**:
  - Натискання кнопки **«Завантажити CV (PDF)»** або комбінації `Ctrl + P` відкриває оптимізовану версію для друку / збереження в один або два аркуші формату A4 (приховуються навігаційні кнопки та зайві елементи, формуючи охайний академічний документ).
- 📱 **Повна адаптивність**:
  - Бездоганне відображення на мобільних телефонах, планшетах, ноутбуках і 4K-моніторах.
- ⚡ **Zero-Dependencies**:
  - Працює автономно без необхідності встановлювати Node.js або зовнішні пакети. Достатньо просто відкрити `index.html` у будь-якому браузері!
- 🔍 **Повна SEO-оптимізація та Open Graph**:
  - Метатеги для пошукових систем (Google, Bing).
  - Open Graph & Twitter Cards прев'ю-зображення (`og-image.png`, 1200x630) для гарного шерингу в Telegram, LinkedIn, Facebook, Discord.
  - Структуровані дані Schema.org (`Person`).
  - Файли `sitemap.xml` та `robots.txt` для індексації пошуковими роботами.

## 📂 Структура проєкту

```text
├── index.html          # Головна розмітка сайту з семантичними тегами та data-i18n ключами
├── 404.html            # Стилізована сторінка помилки 404
├── CNAME               # Прив'язка власного домену kostia-oliinyk.itkamianets.com
├── favicon.ico         # Фавіконка сайту для вкладок браузера
├── robots.txt          # Інструкції для пошукових роботів
├── sitemap.xml         # Карта сайту для індексації в пошуковиках
├── img/
│   ├── favicon.png     # Високоякісна PNG-фавіконка (1024x1024)
│   ├── apple-touch-icon.png
│   ├── og-image.png    # 1200x630 SEO / Open Graph банер для соцмереж
│   └── seo-image.png
├── css/
│   └── style.css       # Оформлення, темна/світла теми, анімації, сітки Grid/Flexbox та @media print
├── js/
│   └── main.js         # Двомовний словник (i18n), перемикання тем, копіювання email та інтерактивні форми
└── README.md           # Документація проєкту
```

## 📋 Відповіді та інженерна філософія у резюме

2. **Підхід до навчання**:
   - Читання офіційної документації, якісні туторіали і лише потім — усвідомлений чистий код.
3. **Підхід до архітектури**:
   - Проєктування правильної структури та чистого коду зі старту, з подальшим системним покращенням під нові задачі.
4. **Ставлення до дизайну та UX**:
   - Охайність та зручність для користувача як першочерговий пріоритет розробки.
5. **Поза кодом / Хобі**:
   - Спортивна риболовля як спосіб перезавантажитися, тренувати витримку, терпіння та отримувати позитивні емоції.
6. **Освіта**:
   - Спеціальність 122 «Комп'ютерні науки», Кам'янець-Подільський національний університет імені Івана Огієнка (КПНУ).

7. **Основний стек**:
   - **Python**, **C++**, **SQL**, а також реляційне моделювання даних та гібридні мобільні застосунки.

   - VS Code, JetBrains Rider, CLion, phpMyAdmin.
9. **Ключові проєкти**:
   - **Гра «Сапер» (Minesweeper)** — курсова робота з фокусом на алгоритми.
   - **Мобільний додаток для змагань з риболовного спорту** — проєкт з курсу «Гібридні мобільні додатки».

## 🏃‍♂️ Як запустити сайт локально

1. Двічі клацніть файл **`index.html`** у вашому провіднику (Windows Explorer), щоб відкрити його в Microsoft Edge, Google Chrome або іншому улюбленому браузері.
2. Також можна відкрити проєкт у **VS Code** і за бажанням запустити розширення **Live Server**.
